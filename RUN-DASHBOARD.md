# Run the dashboard in Cursor / VS Code

Requirements: Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Open the local URL printed in the terminal (normally `http://localhost:5173`).

This cleaned dashboard removes the Micro-Stoppage Events, Analytics, and Machine Performance pages, their navigation entries, event notification UI, event tables, and event-derived overview cards. Live machine status, ACS712 current, MPU6050 vibration, charts, devices, architecture, simulation, reports, settings, and the existing Production Loss module remain available.
